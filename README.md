## 快速开始

纯静态项目，**不需要安装任何依赖、也不需要构建**：

```bash
git clone https://github.com/WilShi/solar-system.git
cd solar-system
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 直接双击 `index.html` 用 `file://` 打开通常也能跑（没有本地贴图请求），
> 但推荐用本地 HTTP 服务，避免不同浏览器对 `file://` 的限制差异。

所有第三方库走 CDN：Three.js r128、OrbitControls 0.128、TWEEN.js 18.6.4、Font Awesome 6.4。
离线环境需把这些脚本下载到本地，并改写 `index.html` 里的 `<script>` / `<link>`。

## 功能特性

### 视觉呈现
- **银河系中心**：超高密度发光点阵，模拟银心区域的超大质量黑洞与高能辐射
- **旋臂结构**：四条主要螺旋臂，展现年轻恒星与星团的分布
- **银晕区域**：球状分布的老年恒星与球状星团
- **星团星云**：包含昴星团、猎户座星云等著名天体
- **动态色彩**：按天体类型与年龄着色（蓝色年轻恒星、红色老年恒星）

### 交互功能
- **360 度旋转**：鼠标拖拽全方位观察
- **多级缩放**：从银河系尺度一路下探到行星细节
- **点击交互**：点击天体打开信息面板，查看统计与描述
- **智能聚焦**：点击后相机平滑飞行并聚焦到目标

### 高级模式
- **漫游模式**：自动巡航银河系各个重要区域
- **科研模式**：叠加银道面、坐标轴与参数网格
- **时间轴模式**：模拟银河系随时间的演化
- **实时参数**：时间速度与点阵密度可实时调节

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖拽 | 旋转视角 |
| 鼠标滚轮 | 缩放场景 |
| 点击天体 | 打开信息面板并聚焦 |
| 信息面板左上角关闭按钮 | 关闭面板 |
| 旋臂按钮 | 显示 / 隐藏螺旋臂结构 |
| 漫游按钮 | 启动 / 停止自动巡航 |
| 科研按钮 | 显示 / 隐藏科研辅助元素 |

| 时间速度滑块（0-10x） | 调节银河系旋转与粒子动画速度 |
| 点阵密度滑块（0.1-3x） | 实时调整粒子数量与视觉密度 |

## 技术实现

- **渲染**：Three.js r128 + WebGL，使用 `THREE.Points` 绘制点阵云
- **粒子规模**：银河系主体约 3 万粒子（银心同量级），各星团 1.5k-5k 粒子，数量随「点阵密度」实时重建
- **四级 LOD**：`galaxy -> region -> system -> detail`，按相机距离切换细节层，远处不加载行星级内容
- **相机过渡**：TWEEN.js 缓动补间，点击天体时平滑飞行聚焦
- **加载进度**：分阶段构建场景，并在加载屏实时反馈进度
- **太阳系数据**：行星轨道按真实 AU 距离建模（0.387 AU ~ 30.07 AU）
- **程序化生成**：旋臂、星团、背景星、星座连线全部由算法生成，不依赖外部数据文件
